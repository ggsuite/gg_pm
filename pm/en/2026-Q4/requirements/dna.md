# DNA

## req-dna-chk: A check proves that the generated DNA files are unchanged

- Status: accepted
- Priority: must
- Statement: Every repo has a check that verifies that the files its DNA generated are unchanged, and the check changes nothing itself
- Why: [publish a ticket in minutes](../goals/publish-a-ticket-in-minutes.md)
  — no hidden work: today the DNA test of a repo writes the DNA anew and
  commits it (`#gg: generated DNA`), in the middle of a ticket
- Acceptance: The check fails when a DNA-generated file differs from what
  the DNA generates, names the file, and leaves the working tree and the
  history untouched — whether it passes or fails
- Note: stated by the user on 2026-11-15; the wording of the acceptance is
  a proposal

## req-dna-src: Changes to skills go into dna_gg

- Status: accepted
- Priority: must
- Statement: A change to a skill of a ggsuite repo is carried over into `dna_gg`, the DNA layer the skills come from
- Why: the skills of a repo are generated by its DNA; a change made only in
  the repo is lost at the next DNA update, and every other repo misses it
- Acceptance: After a ticket that changed a skill in a ggsuite repo,
  `dna_gg` holds the same change, and the check of
  [req-dna-chk](#req-dna-chk-a-check-proves-that-the-generated-dna-files-are-unchanged)
  passes in that repo
- Note: stated by the user on 2026-11-15

## req-dna-eco: The DNA of a repo comes from one ecosystem

- Status: accepted
- Priority: must
- Statement: The DNA layers of a repo come from one ecosystem: the `dna/_generated.json` of a repo lists either pub packages or npm packages, never both
- Why: a Dart repo should not need Node and npm to get its DNA, and a
  TypeScript repo not Dart and pub
- Acceptance: In every repo of the ocean, the layers in
  `dna/_generated.json` that name an ecosystem name the same one
- Note: stated by the user on 2026-11-15. On that day every Dart repo of
  the ticket `lean_publish` listed `@ggdna/dna-github` (npm) next to its
  pub layers
